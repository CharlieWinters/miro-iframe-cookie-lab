the partner app sign in demo

This tab is top level, so it is a first-party context: an identity provider will render here, and cookies written here behave normally. That is the whole reason the board panel sends you out to a tab instead of collecting credentials itself.

Session issued

The token here is unsigned and issued client-side purely so the demo has something to pass around. A real integration returns an opaque session reference or a signed assertion that the panel's backend verifies — never a bearer credential minted in the browser.
